# 🐰 אנגלית עם פופו

אפליקציית ווב (PWA) ללימוד אנגלית לילדים דוברי עברית שמתחילים מאפס.
הממשק כולו בעברית, הכול נשמר מקומית במכשיר, אין שרת ואין מפתחות API, והאפליקציה עובדת גם בלי אינטרנט אחרי ההתקנה.

## מה יש באפליקציה

- **מפת הרפתקה** עם 4 שלבים: אותיות (A–Z בקבוצות של 4–5), מילים ראשונות (10 נושאים), משפטים קצרים, ושיחה וסיפורים.
- **7 משחקים**: שמעי ובחרי, התאמה, זיכרון, בלונים, בני את המילה, סדרי את המשפט, ועני על השאלה.
- **הגייה**: Web Speech API באנגלית (en-US, מהירות 0.8), בחירה אוטומטית של הקול הכי טוב במכשיר, וכפתור 🐢 להשמעה איטית. לחיצה על כל מילה או אות משמיעה אותה.
- **הקראה בעברית** של הוראות, אם במכשיר יש קול עברי. אם אין, כפתורי ההקראה מוסתרים.
- **תעתיק**: כל מילה מופיעה עם אמוג'י, תרגום ותעתיק (cat · קֶט · חתול). אפשר לכבות את התעתיק באזור ההורים.
- **פרסים**: 1–3 כוכבים בכל משחק, מטבעות לקניית מדבקות לאלבום, תגים על הישגים, וקונפטי.
- **על טעות** יש רק משוב עדין, בלי עונש ובלי איבוד נקודות.
- **התקדמות הדרגתית**:
  - תחנה חדשה נפתחת רק אחרי 2 כוכבים בתחנה הקודמת.
  - חזרה מרווחת (שיטת לייטנר) מחזירה מילים שהיו בהן טעויות.
  - הקושי מתאים את עצמו: אחרי 2 טעויות ברצף יש פחות אפשרויות ויותר רמזים, ואחרי 5 הצלחות ברצף הקושי עולה.
- **שיעור היום**: כ-10 דקות שמשלבות חומר חדש וחזרה.
- **אזור הורים**, נעול בתרגיל כפל: התקדמות לפי נושא, מילים קשות, זמן למידה, הגדרות ואיפוס.

## הרצה מקומית

צריך Node.js 18 ומעלה.

```bash
npm install
npm run dev
```

אחר כך פותחים את הכתובת שמופיעה (בדרך כלל http://localhost:5173).
כדי לפתוח את האפליקציה מטאבלט באותה רשת Wi-Fi, מריצים `npm run dev -- --host` ופותחים בטאבלט את כתובת ה-Network שמופיעה.

> ההשמעה תלויה בקולות שמותקנים במכשיר. הכי טוב לעבוד עם Chrome באנדרואיד או Safari באייפד.
> באזור ההורים יש כפתורי "בדיקה" לקול האנגלי ולקול העברי.

## פריסה ל-GitHub Pages

הקובץ `.github/workflows/deploy.yml` בונה ומפרסם את האתר אוטומטית בכל push ל-`main`.
הקובץ `.github/workflows/ci.yml` מריץ את הבדיקות והבנייה על כל Pull Request, בלי לפרסם.
הפעלה חד-פעמית:

1. במאגר ב-GitHub נכנסים ל-**Settings**, ואז ל-**Pages** בתפריט הצד.
2. תחת **Build and deployment**, בשדה **Source**, בוחרים **GitHub Actions**.
3. ממזגים או דוחפים ל-`main`. אפשר גם להריץ ידנית: **Actions**, אחר כך **Deploy to GitHub Pages**, ואז **Run workflow**.

הכתובת תהיה: `https://<שם-המשתמש>.github.io/english-for-kids/`

## התקנה על טאבלט או טלפון

1. פותחים את כתובת האתר (GitHub Pages או כל אחסון HTTPS אחר).
2. **אנדרואיד (Chrome)**: תפריט ⋮, ואז **התקנת אפליקציה** או **הוספה למסך הבית**.
3. **אייפד/אייפון (Safari)**: כפתור השיתוף ⬆️, ואז **הוספה למסך הבית**.
4. פותחים פעם אחת כשיש אינטרנט. מאותו רגע האפליקציה עובדת גם בלי חיבור.

## מבנה הפרויקט

```
src/
  data/             תוכן ב-JSON. כאן מוסיפים מילים ומשפטים
    letters.json      אותיות, צלילים ומילות דוגמה
    words.json        מילים לפי נושאים
    sentences.json    משפטים קצרים
    conversation.json שאלות ותשובות וסיפורים
  lib/
    curriculum.ts     בונה שלבים ותחנות מקבצי ה-JSON, ומגדיר משחקים
    speech.ts         השמעה ובחירת הקול הטוב ביותר
    sounds.ts         אפקטים קוליים שנוצרים בקוד (Web Audio), בלי קבצים
    srs.ts            חזרה מרווחת ובחירת שאלות
    progress.ts       פתיחת שלבים וחישוב כוכבים
    rewards.ts        אווטארים, מדבקות ותגים
    store.tsx         פרופיל ושמירה ב-localStorage
    nav.tsx           ניווט בין מסכים, כולל כפתור "חזור" של אנדרואיד
  components/       הדמות פופו, כפתורי השמעה, קונפטי ורכיבי ממשק
  games/            המשחקים
  screens/          המסכים: פתיחה, מפה, שלב, תחנה, לימוד, שיעור היום, אלבום, תגים, הורים
```

### הוספת תוכן

- **נושא מילים חדש**: מוסיפים אובייקט ל-`topics` ב-`src/data/words.json`, עם `id`, `title`, `emoji` ורשימת `words` של `{ en, he, tr, emoji }`. הנושא יופיע אוטומטית במפה.
- **יחידת משפטים**: מוסיפים ל-`units` ב-`src/data/sentences.json`.
- **סיפור או שאלות**: מוסיפים ל-`stories` או ל-`qa` ב-`src/data/conversation.json`.
- אחרי שינוי מריצים `npm test`. הבדיקות מוודאות שלא חסרים שדות ושאין שתי תמונות זהות באותה תחנה.
